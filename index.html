SETUP

How the database works

  1. Create a Google Sheet and open Extensions → Apps Script.
  2. Paste the supplied google-apps-script.gs into the editor and set your private API key.
  3. Deploy it as a Web App, copy the Web App URL, then paste the URL and matching key above.
  4. The backend automatically creates People, Education, Cleaning, Evangelism and Finance tabs.
Privacy: participation and tithe information can be sensitive. Keep the Google Sheet private and do not share the Web App URL or API key publicly.
